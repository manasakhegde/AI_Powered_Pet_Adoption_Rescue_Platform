KEY DIRECTORIES SUMMARY
=======================

Backend Java Packages:
  - model/          → MongoDB document definitions
  - repository/     → Database access layer
  - service/        → Business logic
  - controller/     → REST API endpoints
  - config/         → Configuration classes
  - dto/            → Data transfer objects
  - security/       → JWT and authentication
  - util/           → Helper utilities

Frontend Folders:
  - pages/          → Full page components
  - components/     → Reusable UI components
  - services/       → API communication
  - hooks/          → Custom React hooks
  - store/          → State management
  - utils/          → Helper functions
  - styles/         → CSS and styling


FILE NAMING CONVENTIONS
=======================

Java Files:
  - Classes:    PascalCase.java (e.g., PetService.java)
  - Interfaces: IPascalCase.java (e.g., IPetRepository.java)
  - Tests:      ClassName + Test.java (e.g., PetServiceTest.java)

JavaScript Files:
  - Components: PascalCase.js (e.g., PetCard.js)
  - Utilities:  camelCase.js (e.g., formatters.js)
  - Hooks:      useCapitalCase.js (e.g., usePets.js)
  - Services:   camelCase.js (e.g., petService.js)

Configuration:
  - application.yml for Spring Boot
  - .env for environment variables
  - config files at project root


DATABASE COLLECTIONS (MongoDB)
===============================

pets:
  - Adoptable pets with details
  - Indexes: adoptionStatus, species, location, microchipId

users:
  - Platform users (adopters, staff, admins)
  - Indexes: email (unique), role, phone, active

adoptions:
  - Adoption applications
  - Indexes: petId, adopterId, applicationStatus, paymentStatus

rescues:
  - Rescue centers and operations
  - Indexes: location, organizationName, status


PORTS CONFIGURATION
===================

Services:
  - Frontend:        3000
  - Backend API:     8080
  - MongoDB:         27017
  - MongoDB Express: 8081
  - Jenkins:         8081 (if running separately)

CI/CD PIPELINE STAGES (Jenkins)
===============================

1. Checkout      → Clone repository
2. Build         → Compile Java and React
3. Test          → Unit and integration tests
4. Quality       → SonarQube analysis
5. Images        → Build Docker images
6. Push          → Push to registry
7. Deploy        → Deploy to staging
8. Smoke Tests   → Verify deployment
9. Security      → Run security scans
